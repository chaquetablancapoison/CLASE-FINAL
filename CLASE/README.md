## Cambios realizados
La interfaz original fue reorganizada utilizando exclusivamente el manejador de geometría `.grid()`.

Se utilizaron:
- `row`
- `column`
- `columnspan`
- `sticky`
- `padx`
- `pady`

No se utilizan `.pack()` ni `.place()` en la interfaz.
